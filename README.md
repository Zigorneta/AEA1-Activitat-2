Mini recreació del joc Fireboy and Watergirl, feta com a pràctica de Scrum amb GitHub Projects.

Dos personatges, foc i aigua, han de recollir cristalls i arribar a la porta sense tocar l'element contrari.

Controls
Fireboy: A / D per moure's i W per saltar
Watergirl: ← / → per moure's i ↑ per saltar
Equip

Asier (Product Owner) · Aitor (Scrum Master) · Toni i Iker (Developers)
